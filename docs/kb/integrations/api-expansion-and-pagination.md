# API Pagination, Expansion & Plugin Items

FOG 1.5 has no equivalent to any of this. Its REST API has no pagination, no
`?expand` relation inlining and no `pluginItems` envelope. The 1.5 page
explains what that means in practice and what to use instead.

- [[1.6/kb/integrations/api-expansion-and-pagination|API Pagination, Expansion & Plugin Items (1.6)]]
- [[1.5/kb/integrations/api-expansion-and-pagination|API Pagination, Expansion & Plugin Items (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
