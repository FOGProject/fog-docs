# Secure Boot - MOK enrollment (Routes A and B)

Both enrollment routes work identically on 1.5 and 1.6: the Secure Boot config
page, the enrollment kit and the boot menu entry are all present on either
version. The only difference is the Setup Mode alternative, which exists only
on 1.6.

- [[1.6/kb/how-tos/secure-boot-mok-enrollment|Secure Boot - MOK enrollment (Routes A and B) (1.6)]]
- [[1.5/kb/how-tos/secure-boot-mok-enrollment|Secure Boot - MOK enrollment (Routes A and B) (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
