# Using the FOG Boot Menu

The menu and its entries are substantially the same on both versions. 1.6
renamed this page from *Client Side Tasks*, and the **Enroll Secure Boot Key**
entry — which originated in 1.6.0 — has since been ported back to the 1.5.x
line, so it is available on either version.

- [[1.6/management/fos/using-fog-boot-menu|Using the FOG Boot Menu (1.6)]]
- [[1.5/management/fos/using-fog-boot-menu|Using the FOG Boot Menu (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
