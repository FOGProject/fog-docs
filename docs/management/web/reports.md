# Report Management

FOG 1.5 has no Reports/Lists split, no date window and no CSV (All) export —
just a single flat, alphabetical menu. 1.6 adds all three, plus a documented
way to add reports of your own.

- [[1.6/management/web/reports|Report Management (1.6)]]
- [[1.5/management/web/reports|Report Management (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
