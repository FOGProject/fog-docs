# Site Scoping

On 1.5 Sites is a plugin you install from **FOG Configuration → Plugin
System**, and it scopes only hosts and users, with no roles or grants. On 1.6
Sites are part of FOG itself: the section is always in the main menu and there
is nothing to enable. Upgrading carries existing sites and their members across.

- [[1.6/management/web/site-scoping|Site Scoping (1.6)]]
- [[1.5/management/web/site-scoping|Site Scoping (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
