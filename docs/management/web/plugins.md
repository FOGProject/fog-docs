# Plugins

The plugin system exists on both versions and is enabled the same way. The
screens are what differ: 1.5 has no single plugin list, using a three-page
activate/install/installed workflow where a plugin's state decides which page
it appears on. The bundled plugin set differs too.

- [[1.6/management/web/plugins|Plugins (1.6)]]
- [[1.5/management/web/plugins|Plugins (1.5)]]

>[!info] Which version am I on?
>Check **FOG Configuration → FOG Settings → General → FOG_VERSION** in the
>web UI, or the version string printed at the top of `installfog.sh`.
